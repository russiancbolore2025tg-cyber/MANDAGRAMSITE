# MandaGram — Официальный сайт на Astro

Исходный код официального сайта нативного клиента Telegram для ПК **MandaGram**, разработанный на базе архитектуры современных веб-приложений на фреймворке **Astro**.

---

## 🚀 О проекте MandaGram

**MandaGram** — это быстрый и независимый клиент Telegram для ПК (Windows 10/11 x64 и Linux x86_64), созданный на базе ядра **TDLib** и **Compose Multiplatform Desktop** с дизайном **Material 3 Expressive**.

Ключевые преимущества:
- **Нативные C ABI плагины:** поддержка динамических библиотек (`.dll`, `.so`), написанных на C++, Rust, Zig и D.
- **Горячая перезагрузка (Hot-Reload):** подмена логики плагинов на лету без перезапуска клиента.
- **Сторожевой таймер Watchdog:** автоматическая изоляция зависших хуков и защита от сбоев в режиме Safe Mode.
- **Material 3 Expressive & ExteraMonet:** адаптивные динамические цветовые палитры (Evening Red, Pistachio, Lavender) и Google Sans Flex.
- **Встроенный медиаплеер LibVLC:** воспроизведение видео, аудио и голосовых с аппаратным ускорением GPU без сторонних кодеков.
- **Приватность:** режим невидимки (Ghost Mode) для скрытного предпросмотра сообщений и аварийная кнопка Panic Mode (`Ctrl+Shift+Escape`).

```

│   ├── robots.txt            # Правила для поисковых систем
│   ├── sitemap.xml           # Полная карта сайта со всеми маршрутами
│   ├── fonts/                # Шрифты Google Sans и Google Sans Flex (TTF & WOFF2)
│   ├── assets/               # Векторные логотипы и графика высокого разрешения

    │   ├── mandagram_logo.svg
    │   ├── vector_shape.svg

    │   ├── Header.astro      # Шапка сайта (логотип, навигация, переключатель тем)
    │   ├── Footer.astro      # Подвал сайта (колонки документации, копирайты, отказ от ответственности)

    │   ├── Base.astro        # Корневой макет (View Transitions, тема, анимации)
    │   └── Kb.astro          # Макет статьи базы знаний и юридических документов

    │   ├── features.ts       # 8 функций клиента с техническими описаниями (RU & EN)

    │   ├── team.ts           # Данные участников команды (роли, ссылки на Telegram, теги)

    │   └── legal.ts          # Правовой статус, политика конфиденциальности и TOS
    ├── styles/               # Стили Material 3 Expressive
    │   ├── global.css        # Токены тем ExteraMonet (Evening Red), кнопки, карусель, мокап окна ПК
    │   └── kb.css            # Стили документации, подсветка синтаксиса кода C/C++/Rust/Zig/D

        ├── index.astro       # Главная страница (RU)
        ├── 404.astro         # Страница ошибки 404
        ├── legal.astro       # Правовой статус (/legal.html)
```

## 🛠 Запуск и сборка

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
# Сервер доступен по адресу: http://localhost:4321
```

### 3. Сборка для продакшна
```bash
npm run build
# Статический сайт генерируется в каталог dist/
```

### 4. Предпросмотр собранного сайта
```bash
npm run preview
```

## 🎨 Особенности дизайна и технологий

1. **Человечный язык без ИИ-слопа:** все тексты, чейнджлоги и статьи документации написаны ясным техническим языком от разработчиков для пользователей.
2. **Точные цвета ExteraMonet Evening Red:** палитра синхронизирована с `Theme.kt` десктопного клиента (основной акцент `#E2B2A2`, фон `#151210`, контейнеры `#1F1815` и `#28201D`).
3. **Мокап окна ПК вместо смартфона:** наглядная интерактивная демонстрация работы плагинов, горячей перезагрузки, Watchdog и плеера в интерфейсе десктопного окна.
4. **Настоящая навигация и поиск:** поддержка клавиатурного фокуса, переключение тем с анимацией View Transitions, стемминг поисковых запросов в базе знаний.
